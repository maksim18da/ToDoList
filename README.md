Ссылка на проект - https://maksim18da.github.io/ToDoList/

Учебное приложение для управления задачами, разработанное на React 19 с использованием сборщика Vite. Проект демонстрирует современные подходы к разработке одностраничных приложений: работу с хуками, Context API, кастомными хуками, localStorage и оптимизацию производительности. Сайт опубликован на GitHub Pages.

Цель работы — изучить и применить на практике современный React (hooks, Context API, memo, useCallback, useMemo), научиться создавать кастомные хуки для переиспользования логики, освоить управление состоянием в приложении без Redux, реализовать сохранение данных в localStorage, разобраться в оптимизации рендеринга компонентов и настроить деплой SPA на GitHub Pages через CI/CD с помощью GitHub Actions.

В проекте используются все основные React-хуки. useState применяется для хранения состояния задач, текста новой задачи и поискового запроса. useEffect используется для синхронизации с localStorage и автофокуса на инпуте. useRef даёт доступ к DOM-элементам — инпуту новой задачи и первой невыполненной задаче для скролла к ней. useCallback делает функции-обработчики стабильными между рендерами. useMemo кеширует вычисления — отфильтрованный список задач и количество выполненных. useContext обеспечивает доступ к глобальному состоянию из любого компонента.

Для управления глобальным состоянием используется Context API. Проблема, которую он решает — это props drilling, когда данные приходится передавать через множество уровней компонентов. Решение — создать контекст TasksContext и обернуть всё приложение в TasksProvider. Провайдер получает данные из кастомных хуков и передаёт их через value всем дочерним компонентам. Компоненты AddTaskForm, SearchTaskForm, TodoInfo, TodoList и TodoItem обращаются к контексту через useContext и берут только то, что им нужно. Это избавляет от необходимости пробрасывать пропсы вручную и делает компоненты независимыми от структуры приложения.

В проекте три кастомных хука. useTasks содержит всю логику управления задачами: массив задач, функции добавления, удаления, удаления всех, переключения статуса выполнения, а также отфильтрованный по поиску список. useIncompleteTaskScroll находит первую невыполненную задачу и создаёт ref для скролла к ней. useTaskLocalStorage — обёртка над localStorage с защитой от битых данных через try/catch. Такое разделение позволяет отделить логику от UI, упрощает тестирование и переиспользование кода.

Оптимизация производительности выполнена несколькими способами. React.memo применён к компонентам TodoItem, TodoInfo, TodoList и SearchTaskForm — они не перерисовываются, если пропсы не изменились. useCallback в useTasks даёт стабильные ссылки на функции, что важно для memo-компонентов. useMemo кеширует тяжёлые вычисления — фильтрацию задач и подсчёт выполненных. Функциональное обновление состояния через setTasks(prev => ...) гарантирует работу с актуальным состоянием и избавляет от проблем с замыканиями.

Работа с localStorage построена на ленивой инициализации useState и useEffect. При первом рендере состояние читается из localStorage один раз — до отрисовки. Если данных нет или они повреждены, возвращается значение по умолчанию. При каждом изменении tasks срабатывает useEffect и сохраняет массив в localStorage. Вся работа с JSON.parse обёрнута в try/catch — это защищает приложение от краша, если в хранилище окажется мусор.

Управление формами реализовано через контролируемые инпуты. Значение поля берётся из состояния, а при вводе обновляется через onInput. Это даёт единый источник правды, возможность валидации в реальном времени и сброс поля после добавления задачи. Поиск работает по такому же принципу — введённый текст хранится в состоянии, а список задач фильтруется через useMemo только при изменении запроса или массива задач.

Для работы с DOM используются useRef и опциональная цепочка. После добавления задачи фокус возвращается на инпут через newTaskInputRef.current?.focus(). Кнопка «Show first incomplete task» вызывает scrollIntoView на элементе первой невыполненной задачи. Опциональная цепочка ?. защищает от ошибок, если ref ещё не привязан к элементу.

Деплой настроен через GitHub Actions. При каждом push в ветку main workflow автоматически запускается: устанавливает зависимости через npm ci, собирает проект через npm run build в папку dist, загружает артефакт через actions/upload-pages-artifact и публикует на GitHub Pages через actions/deploy-pages. В vite.config.js указан base: '/ToDoList/' — без этого стили и скрипты не загрузились бы, потому что сайт хостится в подпапке.

В ходе работы я научился разделять логику и UI через кастомные хуки, избегать props drilling с помощью Context API, оптимизировать рендеринг через memo, useCallback и useMemo, работать с внешними системами через useEffect и ленивую инициализацию, защищать код от ошибок с помощью try/catch и опциональной цепочки, а также настраивать CI/CD для автоматического деплоя React-приложения на GitHub Pages.

Дальнейшие улучшения, которые можно внести: добавить TypeScript для типизации пропсов и состояния, разделить контекст на данные и действия для более тонкой оптимизации, использовать useReducer для сложной логики, покрыть код тестами через Jest и React Testing Library, улучшить доступность с ARIA-атрибутами и навигацией с клавиатуры, добавить категории и приоритеты для задач.
